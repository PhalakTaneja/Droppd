## What counts as a good recommendation
- Free and open-source strongly preferred
- If paid, it must have a genuinely usable free tier -- no subscription-only tools
- Focus: productivity -- getting things done faster (writing, automation,
  file management, window management, terminal tools, note-taking, focus
  and time management, clipboard, screenshots, backups)
- Must be actively maintained (a release or commit within the last year)
- Small and lightweight beats big bloated suites
- Privacy-respecting: nothing that harvests my data
